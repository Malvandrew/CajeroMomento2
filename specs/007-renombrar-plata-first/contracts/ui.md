# UI Contract: Renombrar Banco a Plata First

## Identidad

- El nombre actual del banco se escribe exactamente `Plata First`.
- El monograma asociado al nombre se muestra como `PF`; no se conserva `MP` como marca vigente.
- El nombre y el monograma deben identificar de manera coherente la aplicación en las vistas públicas y autenticadas.

## Puntos de presentación

- El título de la página, encabezado de marca, contenido de presentación, historia, encabezado del panel y pie de página usan la identidad nueva.
- El encabezado de registro y los mensajes que identifican la aplicación usan `Plata First`.
- Los nombres accesibles que incluyen la marca coinciden con el nombre visible y no anuncian la identidad anterior.
- El contenido académico y los mensajes de la aplicación conservan su significado; solo cambia la referencia de marca.

## Compatibilidad y accesibilidad

- El nombre y el monograma permanecen legibles en escritorio, tableta y móvil, sin solaparse con controles ni causar desbordamiento horizontal.
- La navegación, el registro, el inicio de sesión y las operaciones conservan su comportamiento.
- Los datos personales y financieros existentes permanecen sin cambios.
- Las especificaciones históricas no se actualizan como parte de este contrato.
