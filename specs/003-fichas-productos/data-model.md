# Data Model: Fichas de Productos en el Landing

This feature introduces no domain entities, persisted fields, relationships, or state transitions. Product names and descriptions are static presentation content in the landing view; existing account, credit, and transaction data remain unchanged.

## Display Content

| Product | Description |
|---|---|
| Cuenta de ahorros | Ahorra, consigna y retira dinero; genera interés según las condiciones del producto. |
| Cuenta corriente | Administra tus movimientos cotidianos con sobregiro sujeto a las condiciones de la cuenta. |
| Tarjeta de crédito | Realiza compras con tu cupo disponible y paga en cuotas, con intereses según el plazo. |

The descriptions are informative summaries and do not override or add financial rules.
